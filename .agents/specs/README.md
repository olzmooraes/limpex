# Diretório de Especificações de Funcionalidades (Specs)

Este diretório armazena as especificações formais de cada funcionalidade desenvolvida no Limpex, seguindo o padrão de **Spec-Driven Development (SDD)**.

---

## Como criar uma nova especificação:
1. Copie o arquivo [.agents/templates/feature-spec-template.md](file:///c:/projetos/limpex/.agents/templates/feature-spec-template.md).
2. Salve neste diretório com a nomenclatura: `SPEC-<NUMERO>-<nome-da-feature>.md` (ex.: `SPEC-001-setup-e-autenticacao.md`).
3. Preencha todos os campos, incluindo os cenários BDD e critérios de aceite.
4. Conecte a spec à tarefa correspondente em [.agents/backlog/backlog.md](file:///c:/projetos/limpex/.agents/backlog/backlog.md).
